1. Bubble Sort

Brute Force / Exchange

Iterates through the list, comparing adjacent elements and swapping them if out of order. With the swapped flag optimization, it terminates in a single pass on already-sorted arrays.

  • Best Time: Ω(n) (when already sorted)
  • Average Time: Θ(n²)
  • Worst Time: O(n²) (reverse sorted)
  • Auxiliary Space: O(1) (in-place)
  • Stability: Stable
  • Practical Use: Pedagogical demonstration and educational tracing.

2. Selection Sort

Decrease & Conquer

Divides the array into sorted and unsorted regions. Repeatedly searches the unsorted region for the minimum element and swaps it with the first unsorted position.

  • Best Time: Ω(n²) (always searches unsorted region)
  • Average Time: Θ(n²)
  • Worst Time: O(n²)
  • Auxiliary Space: O(1) (in-place)
  • Stability: Unstable (standard in-place)
  • Practical Use: Systems where memory write cycles are costly (at most n-1 swaps).

3. Insertion Sort

Incremental Approach

Builds a sorted array one element at a time by picking the next key and shifting larger elements in the sorted prefix to the right to make room.

  • Best Time: Ω(n) (nearly or already sorted)
  • Average Time: Θ(n²)
  • Worst Time: O(n²)
  • Auxiliary Space: O(1) (in-place)
  • Stability: Stable
  • Practical Use: Small datasets (n < 30) and nearly-sorted inputs. Core component of Timsort.

4. Merge Sort

Divide & Conquer

Divides the array recursively into two equal halves until single-element arrays remain, then merges them in sorted order using auxiliary buffers.

  • Best Time: Ω(n log n)
  • Average Time: Θ(n log n)
  • Worst Time: O(n log n) (guaranteed bound)
  • Auxiliary Space: O(n) (out-of-place)
  • Stability: Stable
  • Practical Use: Linked list sorting, external tape/disk sorting, systems requiring guaranteed O(n log n).

5. Quick Sort

Divide & Conquer / Partitioning

Selects a pivot element and partitions the array into elements smaller than or equal to the pivot on the left and larger on the right, then recurses on both halves.

  • Best Time: Ω(n log n)
  • Average Time: Θ(n log n)
  • Worst Time: O(n²) (mitigated with median pivot)
  • Auxiliary Space: O(log n) (recursion stack)
  • Stability: Unstable
  • Practical Use: Default general-purpose in-memory sorting of arrays due to superior cache locality.
